Falcosidekick {{ .Chart.AppVersion }} receives Falco events at:

  {{ $scheme }}://{{ $fullname }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/

In the Falco chart, set:

  falco:
    json_output: true
    json_include_output_property: true
    http_output:
      enabled: true
      url: "{{ $scheme }}://{{ $fullname }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/"

{{- if .Values.ui.enabled }}

The web UI and the API are served on the management port, read-only{{ if dig "api" "allow_writes" false $cfg }} except that api.allow_writes is true{{ end }}:
{{- if .Values.management.service.enabled }}

  {{ $scheme }}://{{ $fullname }}-management.{{ .Release.Namespace }}.svc:{{ .Values.management.service.port }}/

  The API has no authentication: restrict who can reach this Service.
{{- else }}
{{- $port := dig "management" "listen_port" 2802 $cfg | int }}

  kubectl --namespace {{ .Release.Namespace }} port-forward deploy/{{ $fullname }} {{ $port }}
  open {{ $scheme }}://127.0.0.1:{{ $port }}/
{{- end }}
